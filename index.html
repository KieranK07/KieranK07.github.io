~/backquest · rust

backquest

Gives a Windows 11 PC with no network of its own internet through a Quest 3's WiFi, over a USB-C cable.

gnirehtet reverse-tethers a phone through a PC. backquest runs it the other way round: a wintun adapter on the PC captures the machine's traffic, and a relay on the headset, reached through adb forward, carries it out over the Quest's WiFi. Validated end to end on real hardware.

Rust wintun adb Quest 3

~/Nexus · go

Nexus

A self-hosted life dashboard for exactly one user, shipped as a single Go binary.

Gmail, calendar, net worth, smart home and a browser PTY on one screen; the React front end is embedded with go:embed and state lives in SQLite. Security is the point: passkey-only WebAuthn login with a one-time Argon2id recovery code, secrets encrypted at rest with AES-256-GCM, an append-only audit log, and a server that binds to loopback and is reached only through a Cloudflare Tunnel. Money is integer cents; nothing in the running total is a float.

Go React SQLite WebAuthn Cloudflare Tunnel

// mac records, the pc's gpu transcribes, the note lands in the vault. a sleeping pc never costs a lecture

~/notables · swift + node

notables

Records a lecture on the Mac, transcribes it on a Windows GPU, and files it into a Markdown vault.

A SwiftUI recorder hands the audio over Tailscale to a dependency-free Node server on the PC, which runs whisper large-v3 on CUDA and then has Claude file the transcript into the vault. A durable outbox and inbox mean a sleeping PC never costs a lecture; the transcript hits disk before any model is called; a per-course glossary feeds whisper's initial prompt; and any silent drop in quality has to show up in the UI.

Swift SwiftUI Node whisper Tailscale
